# X Thread Skill

A thread for X: standalone tweets building one idea. Concise, punchy, no filler.
1. Tweet 1 is the hook - sharp thesis, earns the next tap, no 'a thread'.
2. Tweets 2-4 unpack it: broken default then better principle, one idea per tweet.
3. Tweets 5-6 ground in real brand/product evidence (allowed claims only).
4. Final tweet lands the takeaway, no 'follow me', no bait.
Rules: each tweet <=280 chars and stands alone; 5-7 tweets; plain language; at most one emoji; no numbering in text.
Output contract: return ONLY a JSON array of tweet objects [{"text":"..."}] - no prose, no code fences, no numbering.
